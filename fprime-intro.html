décomposer = casser en morceaux.

On divise par le plus petit premier possible. On recommence avec le quotient. Jusqu'à n'avoir que des premiers. Y'a qu'une seule façon de le faire par nombre — c'est son empreinte.

l'algo, en 4 gestes.

Oublie le C pour l'instant. Voilà ce que ton programme doit faire. Rien de plus.

commence par diviser par 2

Le plus petit premier. Tu testes : n % 2 == 0 ?

tant que ça divise, tu restes

Si n=8 → 2, 2, 2. Même diviseur tant que ça marche. Pas besoin d'avancer.

quand ça divise plus, tu ++

2 → 3 → 4 → 5... Pas besoin de tester si le diviseur est premier. Si les 2 sont épuisés, 4 divisera jamais rien. Le test se fait tout seul.

stop quand n vaut 1

C'est fini. printf("\n") et tchao.

42 qui se fait démonter en live.

Suis le programme, ligne par ligne. Chaque ligne = une itération.

trace · ./fprime 42
// start: n=42, div=2
42 % 2 == 0 ? YES → print "2", n = 21
21 % 2 == 0 ? no → div++ (3)
21 % 3 == 0 ? YES → print "*3", n = 7
7 % 3 == 0 ? no → div++ (4)
7 % 4 == 0 ? no → div++ (5)
7 % 5 == 0 ? no → div++ (6)
7 % 6 == 0 ? no → div++ (7)
7 % 7 == 0 ? YES → print "*7", n = 1
// n == 1 → exit. print "\n"

output: 2*3*7
t'as suivi ? l'algo c'est juste ça, répété.

4 pièges à pas oublier.

Avant même la factorisation, le sujet demande de gérer ces 4 inputs. Si tu les rates, le test tombe.

./fprime → \n
Zéro argument → juste un newline.
./fprime 42 21 → \n
Plus d'un arg → pareil. Règle : argc != 2.
./fprime 1 → 1
1 n'a pas de facteurs. Affiche 1 direct.
./fprime 9539 → 9539
9539 est premier. div grimpe jusqu'à 9539 et stop.

le piège du séparateur.

Regarde bien : 2*3*7, pas 2*3*7*. Il y a n-1 étoiles pour n facteurs. Classique trap.

✦ le move ✦

Imprime le * AVANT chaque facteur, sauf le premier.

Tu gardes un flag first = 1. Dès qu'il passe à 0, tu préfixes chaque nombre par *. Simple, efficace, pas de buffer.

// pseudo-C
if (first) { printf("%d", div); first = 0; }
else { printf("*%d", div); }

par où t'attaques.

Avant d'ouvrir fprime.c, tu connais la charpente. Tu tapes, tu remplis les cases.

A

check argc

Si argc != 2 → printf("\n") + return 0.

B

parse l'int

int n = atoi(argv[1]).

C

boucle

div=2. Tant que n > 1. Inner : tant que n % div == 0, print + divise.

D

newline final

printf("\n") après la boucle.
