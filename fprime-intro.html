01 concret d'abord

Le programme doit faire ça.

On commence par voir le résultat avant de comprendre comment. C'est toujours plus simple dans ce sens.

$ ./fprime 42

$ ./fprime 225225

$ ./fprime 9539 # celui-là est premier

$ ./fprime 1

$ ./fprime # sans argument : juste un \n

$ ./fprime 42 21 # trop d'args : pareil, juste un \n

et c'est tout. 6 comportements à capter. Rien de plus.

02 la base

Un nombre premier c'est quoi, déjà ?

Un nombre qui ne se divise proprement que par 1 et par lui-même. Pas de reste. C'est un "atome" mathématique : indivisible.

03 décomposer

Casser un nombre en morceaux premiers.

Tu prends un nombre. Tu le divises par un premier, tu continues avec le reste, et ainsi de suite jusqu'à avoir que des premiers. Y'a qu'une seule façon de le faire — c'est un truc unique à chaque nombre, comme une empreinte.

42 = 2 × 3 × 7
04 l'algo dans ta tête

4 mouvements. Pas plus.

Oublie le C pour l'instant. Voilà ce que le programme fait, dans l'ordre. Aucune magie.

1

Commence par diviser par 2

C'est le plus petit premier. Tu testes : n % 2 == 0 ?

2

Tant que ça divise, tu restes sur le même

Si n = 8, tu divises par 2 → 4 → 2 → 1. Tu écris 2*2*2. Pas besoin de changer de diviseur tant que ça marche.

3

Quand ça divise plus, tu incrémentes

2 → 3 → 4 → 5... Pas besoin de tester si le diviseur est premier. Si tu as épuisé les 2, alors 4 ne divisera jamais rien non plus. Le test se fait tout seul.

4

Tu t'arrêtes quand n vaut 1

Terminé. Tous les facteurs sont sortis. printf("\n") et tchao.

05 l'algo qui tourne

Regarde 42 se faire démonter en direct.

Chaque ligne = une itération de boucle. Tu suis le chemin du programme comme un débugueur mental.

trace · ./fprime 42
// départ : n = 42, div = 2
42 % 2 == 0 ? YES → print "2", n = 21
21 % 2 == 0 ? no → div++
21 % 3 == 0 ? YES → print "*3", n = 7
7 % 3 == 0 ? no → div++
7 % 4 == 0 ? no → div++
7 % 5 == 0 ? no → div++
7 % 6 == 0 ? no → div++
7 % 7 == 0 ? YES → print "*7", n = 1
// n == 1 → on sort. print "\n"

final output → 2*3*7

t'as suivi ? l'algo c'est juste ça, répété jusqu'à n=1.

06 les pièges du sujet

4 cas spéciaux à pas oublier.

Avant même la factorisation, le sujet te demande de gérer ces 4 inputs particuliers. Si tu les oublies, le test échoue direct.

./fprime → \n
Zéro argument → juste un newline.
./fprime 42 21 → \n
Plus d'un arg → pareil. La règle : argc != 2.
./fprime 1 → 1
1 n'a pas de facteurs premiers, affiche 1 direct.
./fprime 9539 → 9539
9539 est premier. L'algo va incrémenter div jusqu'à 9539, qui divise, et c'est fini.
07 le piège visuel

Le séparateur * t'enmerde ?

Regarde : 2*3*7, pas 2*3*7*. Il y a n-1 étoiles pour n facteurs. Classique trap.

✦ le move

Imprime le * AVANT chaque facteur — sauf le premier.

Tu gardes un flag first = 1. Dès qu'il est à 0, tu préfixes chaque nombre par *. Simple.

// pseudo-C
if (first) { printf("%d", div); first = 0; }
else { printf("*%d", div); }
08 par où commencer

Ton squelette mental.

Avant d'ouvrir fprime.c, tu connais déjà l'ossature. Quand tu tapes, t'as plus qu'à remplir les cases.

A

Check argc

Si argc != 2 → printf("\n") et return 0.

B

Parse l'int

int n = atoi(argv[1]).

C

Boucle

div = 2. Tant que n > 1. Inner : tant que n % div == 0, divise + print.

D

Newline final

Un printf("\n") à la toute fin, après la boucle.
