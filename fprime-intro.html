02 · DÉCOMPOSITION

Factoriser, c'est casser un nombre en produit de premiers

Exemple avec 42. L'idée : on descend en divisant à chaque étape jusqu'à tomber sur des premiers.

42 = 2 × 3 × 7

Les ronds verts sont des premiers (on peut plus diviser). Le résultat final c'est le produit de toutes les feuilles.

03 · L'ALGORITHME

4 étapes, pas plus

Oublie le code pour l'instant. Voilà ce que ton programme doit faire, pas à pas :

1

Commencer par le plus petit diviseur

Le plus petit premier c'est 2. Tu testes : est-ce que n est divisible par 2 ?

2

Tant que ça divise, tu restes sur le même diviseur

Si n = 8, tu divises par 2 puis 4 puis 2 puis 1. Tu écris 2*2*2.

3

Quand ça divise plus, tu incrémentes le diviseur

Passe de 2 à 3, de 3 à 4, etc. Pas besoin de tester si le diviseur est premier lui-même — si n n'est plus divisible par 2, il ne le sera pas par 4 non plus.

4

Tu t'arrêtes quand n vaut 1

C'est terminé. Tous les facteurs ont été extraits. Affiche \n et return 0.

04 · TRACE

L'algo qui tourne sur 42

Visualise exactement ce qu'il se passe dans la tête du programme :

./fprime 42
// État initial : n=42, div=2
→ 42 % 2 == 0 ? OUI → print "2", n = 42/2 = 21
→ 21 % 2 == 0 ? NON → div++ (div=3)
→ 21 % 3 == 0 ? OUI → print "*3", n = 21/3 = 7
→ 7 % 3 == 0 ? NON → div++ (div=4)
→ 7 % 4 == 0 ? NON → div++ (div=5)
→ 7 % 5 == 0 ? NON → div++ (div=6)
→ 7 % 6 == 0 ? NON → div++ (div=7)
→ 7 % 7 == 0 ? OUI → print "*7", n = 7/7 = 1
→ n == 1 ? STOP → print "\n"

output: 2*3*7

06 · AFFICHAGE

Le piège du séparateur *

Regarde : 2*3*7, pas 2*3*7*. Il y a n-1 étoiles pour n facteurs. Comment gérer ça sans * en trop à la fin ?

Technique classique en C :

Imprimer le * AVANT chaque facteur, sauf le premier. Tu gardes un flag first = 1, et tu l'abaisses après la première impression.

pseudocode
// première fois : on affiche juste le chiffre
// fois suivantes : on affiche "*chiffre"

if (first) { printf("%d", div); first = 0; }
else { printf("*%d", div); }

Il existe d'autres techniques (imprimer le * APRÈS et trim à la fin, ou concaténer dans un buffer), mais celle-ci est la plus simple avec juste printf.

07 · SQUELETTE

Par où commencer ton code

Avant d'ouvrir fprime.c, tu sais que tu auras besoin de :

A

Vérifier le nombre d'arguments

Si argc != 2 → printf("\n") et return 0.

B

Convertir le string en int

Avec atoi(argv[1]). Tu obtiens ton n.

C

Boucler

Un diviseur div = 2. Une boucle externe qui tourne tant que n > 1. Une boucle interne (ou un if) qui divise tant que n % div == 0.

D

Print final

Un printf("\n") à la toute fin.

La règle d'or

Ne code pas tant que tu peux pas expliquer l'algo à voix haute sur un papier. Si tu bloques sur le code, c'est souvent que tu comprends pas encore assez l'algo.
