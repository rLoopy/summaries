🔑 À observer

  • Les 3 chemins possibles dans main : (1) silent exit si pas d'args, (2) success avec free, (3) erreur avec "Error" sur stderr.
  • stderr ≠ stdout : "Error\n" est écrit sur fd 2, pas fd 1. C'est la convention Unix pour les erreurs. Dans le shell, stderr s'affiche quand même à l'écran, mais il est séparable.
  • Exit code 0 = success, non-zéro = erreur. Le shell peut utiliser cette info (ex: ./push_swap ... && echo ok).
  • free(values) uniquement dans le cas success. Dans le cas erreur, parse_args a déjà tout libéré en interne avant de renvoyer NULL.
  • Le scénario "silent exit" n'affiche rien — ni stdout, ni stderr. C'est ce que demande le sujet pour "aucun argument".
