🔑 Les 3 moments clés

  • malloc fait apparaître le "chunk" dans le heap. node (dans le stack frame) contient maintenant l'ADRESSE de ce chunk.
  • Initialisation : on remplit val et next (qui étaient garbage après malloc) avec des valeurs propres.
  • Return : la fonction sort, son stack frame disparaît. Mais le heap chunk survit — c'est le propre du heap. L'appelant reçoit l'adresse du chunk.
