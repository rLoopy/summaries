    🔑 À observer en regardant

    • tokens et values sont 2 allocations distinctes (visibles dans "mémoire allouée"). tokens est free'd en cours de route, values survit pour être renvoyé.
    • Dans les cas d'erreur (abc, doublon), regarde bien comment la mémoire est nettoyée avant le return NULL. Zéro leak, c'est la discipline 42.
    • Le *n = ... qui écrit dans n de main est symbolisé par la mise à jour du champ "n (dans main)". C'est le pattern "output parameter".
    • Les 2 formats d'input (3 1 4 2 vs "3 1 4 2") produisent EXACTEMENT le même tokens après tokenize. Magie de ft_split.
