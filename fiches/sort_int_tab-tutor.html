Ce que le tutor révèle — les 3 bugs

  
    
    
  1. Structure inversée : ton while (i < size-1) est à l'extérieur et while (swaped) à l'intérieur. C'est l'inverse d'un vrai bubble sort. Résultat : dès que swaped=0, le reste de l'array n'est plus balayé.
    2. 
    
  2. Comparaison inversée : if (tab[i] < tab[i+1]) swap quand c'est déjà dans l'ordre croissant. Tu tries en décroissant (ou pas du tout selon l'input).
    3. 
    
  3. i jamais reset : i part à 0 dans les déclarations, puis i++ monte jusqu'à size-1. Même si tu corrigeais le reste, tu ne ferais qu'une seule passe.
    4. 
  

  

    💡 Le fix : inverse les deux while, mets swaped = 0 avant le while intérieur, reset i = 0 au début de chaque passe, change < en >.
