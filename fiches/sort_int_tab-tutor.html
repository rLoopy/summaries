🐛 Les 2 bugs qui restent (et qui font boucler à l'infini)

  1. swaped = 0 au mauvais endroit (ligne 11) : il est DANS le while intérieur → il s'écrase à chaque paire visitée. Il devrait être avant le while intérieur, une seule fois par passe, pour signaler "personne n'a swapé pendant cette passe".
  2. i jamais reset entre les passes : i = 0 n'est fait qu'une fois dans les déclarations. Après la première passe, i = size et y reste. Quand l'outer reboucle, l'inner ne rentre plus → mais swaped reste à 1 (du dernier swap) → boucle infinie ♾️.
💡 Le fix : sors swaped = 0 avant le while intérieur, et ajoute i = 0 juste en dessous. Comme ça chaque passe repart de zéro et peut vraiment déclarer "rien n'a bougé".
