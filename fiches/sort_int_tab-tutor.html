🐛 Les 3 bugs que le debugger révèle

  1. Structure inversée : while (i < size-1) est à l'extérieur, while (swaped) à l'intérieur. C'est l'inverse d'un bubble sort. Dès que swaped=0, le reste du tableau n'est plus balayé.
  2. Comparaison à l'envers : if (tab[i] < tab[i+1]) swap quand c'est DÉJÀ dans l'ordre croissant. Pour trier croissant il faut >.
  3. i jamais reset : i est initialisé à 0 une seule fois, puis i++ monte. Même si tu corrigeais le reste, tu ne ferais qu'une seule passe au lieu de reboucler tant que ce n'est pas trié.
💡 Le fix : inverse les deux while, mets swaped = 0 avant le while intérieur, reset i = 0 au début de chaque passe, change < en >.
