Les opérations bitwise

shift, mask, et les 2 formules magiques

§4.1 — Le shift droit >>

L opérateur >> décale les bits d un nombre vers la droite. Le bit qui sort à droite est perdu, et un 0 apparaît à gauche.

c     = 01010011 = 83
c >> 1 = 00101001 = 41   // 1 a sorti à droite, 0 entré à gauche
c >> 2 = 00010100 = 20
c >> 7 = 00000000 = 0    // le bit 7 original est maintenant en position 0
★ L astuce
c >> i amène le bit en position i à la position 0 (tout à droite).

Mathématiquement : c >> 1 = c / 2 (division entière). C est une opération très rapide pour le CPU.

§4.2 — Le shift gauche <<

L opérateur << fait l inverse : décale vers la gauche. Le bit qui sort à gauche est perdu, et un 0 apparaît à droite.

c     = 00001010 = 10
c << 1 = 00010100 = 20   // 0 entré à droite
c << 2 = 00101000 = 40
c << 3 = 01010000 = 80

Mathématiquement : c << 1 = c × 2.

§4.3 — L AND bitwise &

L opérateur & compare 2 nombres bit à bit. Pour chaque position, le résultat est 1 seulement si les deux bits sont 1.

  10110100
& 01100110
─────────────
  00100100

Position 7 : 1 & 0 = 0
Position 6 : 0 & 1 = 0
Position 5 : 1 & 1 = 1
... etc

§4.4 — Le masque & 1

Le nombre 1 en binaire 8 bits c est 00000001 — uniquement le bit 0 est à 1. Donc n & 1 donne :

  • 1 si le bit 0 de n est à 1
  • 0 si le bit 0 de n est à 0
  • Tous les autres bits sont écrasés à 0
  01010011  (= 83)
& 00000001  (= 1)
─────────────
  00000001  (= 1)
★ & 1 = filtre
n & 1 garde uniquement le bit 0 de n. Résultat = 0 ou 1.

§4.5 — La formule magique (c >> i) & 1

En combinant >> et & 1, on obtient une formule pour extraire le bit à n importe quelle position :

★ (c >> i) & 1
  1. c >> i : amène le bit i en position 0
  2. & 1 : garde uniquement la position 0
  3. Résultat : 0 ou 1, c est la valeur du bit i

Exemple avec 'H' = 72 = 01001000 :

i(72 >> i) & 1Résultat
7(72 >> 7) & 1 = 0 & 10
6(72 >> 6) & 1 = 1 & 11
5(72 >> 5) & 1 = 2 & 10
4(72 >> 4) & 1 = 4 & 10
3(72 >> 3) & 1 = 9 & 11
2(72 >> 2) & 1 = 18 & 10
1(72 >> 1) & 1 = 36 & 10
0(72 >> 0) & 1 = 72 & 10

Bits extraits : 0 1 0 0 1 0 0 0 = 'H' ✓. C est cette formule que le client utilise pour envoyer les bits.

§4.6 — L OR bitwise |

L opérateur | compare 2 nombres bit à bit. Résultat = 1 si au moins un des deux bits est 1.

  00001010
| 00000001
─────────────
  00001011

c | 1 met le bit 0 à 1 sans toucher aux autres. C est l opération inverse de & 1 qui extrayait — ici on ajoute un 1.

§4.7 — La formule (c << 1) | bit

Côté server, on doit reconstruire un char à partir des bits reçus. La formule c est :

★ c = (c << 1) | bit
  1. c << 1 : décale tout d 1 cran à gauche, libère la position 0
  2. | bit : place le nouveau bit en position 0
  3. Après 8 itérations, c contient le char complet

Exemple : on reçoit dans l ordre les bits 0 1 0 0 1 0 0 0 (= 'H') :

Bit reçuc << 1| bitc final
00 << 1 = 0| 00 = 00000000
10 << 1 = 0| 11 = 00000001
01 << 1 = 2| 02 = 00000010
02 << 1 = 4| 04 = 00000100
14 << 1 = 8| 19 = 00001001
09 << 1 = 18| 018 = 00010010
018 << 1 = 36| 036 = 00100100
036 << 1 = 72| 072 = 01001000 ('H') ✓

§4.8 — Récap

★ Les 4 opérateurs
  • >> shift droit — divise par 2, perd le bit 0
  • << shift gauche — multiplie par 2, perd le bit 7
  • & AND bitwise — 1 si les deux bits sont 1
  • | OR bitwise — 1 si au moins un bit est 1
★ Les 2 formules à retenir
  • Côté client : (c >> i) & 1 extrait le bit à la position i
  • Côté server : (c << 1) | bit ajoute un bit à droite
Si tu peux expliquer ces 2 formules en defense, tu démontres que tu maîtrises la mécanique fondamentale du projet.
