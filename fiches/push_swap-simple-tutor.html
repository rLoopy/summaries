🔑 Ce que tu vois

  • Le code reste sur main.c en permanence. La ligne active est highlight en jaune (ou vert = OK, rouge = erreur, bleu = silent exit).
  • Quand parse_args est appelé, un panneau "parse_args — résumé" apparaît dans la barre d'état avec le résultat : soit [3, 1, 4, 2] + n, soit NULL + la raison de l'erreur.
  • argv est l'input fixe. n est mis à jour via le pointeur (*n) pendant parse_args. values passe de NULL à un tableau d'ints ou reste NULL en cas d'erreur.
  • stderr ne reçoit "Error" que dans les scénarios d'erreur. exit code final : 0 pour les 2 premiers scénarios (silent + success), 1 pour les erreurs.
