CHAPITRE 12

Checklist & README

à cocher avant de rendre, et le README que le sujet exige

§12.1 — Checklist mandatory

★ Avant de dire "c'est fini"
  • ☐ make compile sans warning (-Wall -Wextra -Werror)
  • ☐ make deux fois → « Nothing to be done » (pas de relink)
  • ☐ norminette OK sur tous les .c et .h
  • ☐ La fenêtre s'ouvre et affiche la map avec des images
  • ☐ Déplacement WASD dans les 4 directions
  • ☐ On ne traverse pas les murs
  • ☐ Compteur de moves affiché dans le shell à chaque pas
  • ☐ On ramasse les C ; sortie possible seulement quand tous ramassés
  • ☐ ESC ferme proprement
  • ☐ Croix rouge ferme proprement
  • ☐ Toutes les maps invalides → Error\n + message, jamais de crash
  • ☐ Valgrind clean (hors reliquats MLX/X11 connus), via ESC et croix
  • ☐ Dossiers maps/ et textures/ présents dans le repo
  • ☐ README.md conforme (§ 12.2)

§12.2 — Le README obligatoire (v5.0)

Le sujet (chapitre VI) impose un README.md à la racine avec un contenu minimal précis :

★ Sections exigées
  • Première ligne en italique, exactement : This project has been created as part of the 42 curriculum by <login>
  • Une section Description : le but du projet + un aperçu
  • Une section Instructions : compilation, installation, exécution
  • Une section Resources : références (docs, tutos) + comment l'IA a été utilisée, pour quelles tâches et quelles parties
  • Sections additionnelles au besoin (exemples d'usage, choix techniques…)
★ La section "usage de l'IA"
La v5.0 du sujet (chapitre IV + VI) demande explicitement de documenter ton usage de l'IA. Sois honnête et précis : « j'ai utilisé l'IA pour comprendre le flood fill / débugger le link MLX », pas « l'IA a écrit mon projet ». Et surtout : tu dois pouvoir tout expliquer en defense (chapitre IV : du code que tu ne sais pas justifier = échec).

§12.4 — Le mot de la fin

★ Stratégie gagnante
Fais le mandatory parfait avant tout : c'est la seule façon que ton bonus soit même regardé. La difficulté de so_long n'est pas l'algo, c'est la rigueur — parsing robuste, flood fill correct, zéro leak. Coche toute la liste du § 12.1 et tu rentres en defense serein.

Bon courage 🐬 — et n'oublie pas : tu dois pouvoir expliquer chaque ligne.
