fprime
quick recap ↓

Factorisation en premiers. Zéro math, juste un while + if/else.

🎯 l'algo en 5 points
  1. Guard : argc != 2 → printf("\n"), return.
  2. Parse : int n = atoi(argv[1]).
  3. Cas spéciaux : n < 2 (couvre 0 et 1) → printf("%d\n", n), return.
  4. Loop : div = 2, while (n > 1). Si n % div == 0 : print + divise + * si n > 1. Sinon div++.
  5. Final : printf("\n").
💾 code final
#include <stdio.h> #include <stdlib.h> int main(int argc, char **argv) { /* Edge case : il faut exactement 1 argument */ if (argc != 2) { printf("\n"); return 0; } /* Convertit le string en int */ int n = atoi(argv[1]); /* Cas spéciaux : 0 ou 1 → affiche tel quel et sort (pour 1, le sujet veut littéralement "1") */ if (n < 2) { printf("%d\n", n); return 0; } /* On commence par le plus petit diviseur possible */ int div = 2; /* Tant qu'il reste quelque chose à factoriser */ while (n > 1) { /* div divise n : on écrit le facteur et on divise */ if (n % div == 0) { printf("%d", div); n /= div; /* S'il reste des facteurs à venir, on met un '*' */ if (n > 1) printf("*"); } /* div divise plus : on passe au suivant (pas besoin de tester si div est premier : les non-premiers sont automatiquement sautés) */ else div++; } printf("\n"); return 0; }
🎨 patterns clés
  • Pas de test de primalité : quand tu incrémentes div et qu'il tombe sur un non-premier (4, 6, 8…), n % div ne sera jamais 0 — parce que les premiers de ce non-premier ont déjà été retirés. Le test se fait tout seul.
  • Séparateur après, conditionnel : if (n > 1) printf("*"). S'il reste du taf, on met un *. Sinon rien → pas de trailing star.
  • Early return pour n < 2 : couvre 0 et 1 d'un coup. Le sujet veut "1" pour ./fprime 1, et le loop while (n > 1) ne rentrerait jamais donc faudrait un cas spécial de toute façon.
  • Pas de variable "first" : le flag est inutile avec le pattern "séparateur après". Gain : 1 variable en moins.
  • Autorisés : printf + atoi (pas write comme dans rev_wstr/rostring). Plus simple : printf("%d", div).
⚠️ les pièges
  • Oublier le if (n > 1) avant le * → tu sors "2*3*7*" au lieu de "2*3*7". Classic.
  • Oublier le cas n = 1 → le while ne rentre jamais, aucune output, alors que le sujet veut "1".
  • Démarrer div = 1 → boucle infinie (n % 1 == 0 toujours, n ne change pas de valeur utile).
  • Incrémenter div même quand il divise → tu loupes les facteurs répétés comme dans 8 = 2×2×2.
  • Oublier n /= div → boucle infinie, tu imprimes "2" à jamais pour n = 42.
  • argc > 2 (ex: ./fprime 42 21) → juste \n, pareil que pas d'arg. Le != 2 gère les 2 cas.
🧠 mental model
  • Le loop entier = "je divise tant que je peux, sinon j'avance".
  • div est jamais un nombre premier explicitement — mais par construction, les facteurs qu'il trouve SONT toujours premiers (les composés ayant déjà été "épuisés" par leurs premiers).
  • Si n = premier dès le départ (ex: 9539), div monte lentement (1 incrément par itération) jusqu'à atteindre n lui-même. C'est le pire cas en perf mais ça marche.
  • Pattern réutilisable : "sinon j'avance" → le div++ dans le else. Classique pour les itérations qui cherchent quelque chose.
la règle d'or :
à chaque tour : soit div divise (j'écris + divise), soit il divise plus (j'avance).
if (n > 1) printf("*") : séparateur SEULEMENT s'il reste du taf après.
