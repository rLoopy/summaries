💡 Le pattern "iterator + callback"

Cette fonction ne sait rien de ce que fait f. Elle promet juste : "je passe sur chaque node et je te file son data". Ce que f en fait est ton problème — afficher, multiplier, free, compter, peu importe.

Dans les 3 exemples, f = ft_putnbr qui fait printf("%d", *(int *)data). Mais ça marcherait avec n'importe quelle void f(void *).

C'est le même pattern que sort_list (où cmp est le callback). Une fois que t'as compris un, l'autre est gratuit.
