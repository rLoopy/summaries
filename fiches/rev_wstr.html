4 cas. même séparateur (un seul espace), ordre des mots inversé.

c'est quoi un "mot", au juste ?

attention : espaces OU tabs comme séparateur !

Un mot = un groupe de caractères délimité par des espaces et/ou des tabs, ou par le début/la fin de la string.

Dans le sujet officiel c'est précisé : ' ' ET '\t' peuvent séparer. Les tests n'utilisent qu'un espace simple entre mots (pas de tabs multiples), mais ton code doit gérer les deux.

Wingardium ␣ Leviosa
mot
séparateur (space ou tab)
un mot, un bloc. un séparateur, rien à print.

la stratégie : parcourir à l'envers.

Plutôt que de découper la string en tableau de mots (malloc, copies, etc.), on walk à l'envers sur la string originale et on print chaque mot dès qu'on le trouve.

Avantage : zéro malloc nécessaire (même si malloc est autorisé). On utilise juste deux index (start et end) et on write des segments de la string originale.

✦ l'idée ✦

Deux pointeurs : end (droite du mot) et start (gauche du mot).

Tu pars de la fin de la string. Tu skip les séparateurs vers la gauche. Quand tu touches un char réel → c'est la end du mot. Tu continues vers la gauche jusqu'à retrouver un séparateur (ou le début) → c'est le start. Tu write le segment [start .. end]. Tu continues.

l'algo, en 5 gestes.

même logique que fprime : comprends avant de coder

Oublie le C. Voilà ce que ton programme fait, pas à pas.

trouve la longueur de la string

Boucle while (argv[1][i]) pour obtenir len. Position-toi à i = len - 1.

skip les séparateurs vers la gauche

Tant que str[i] == ' ' ou '\t', décrémente i. Si i < 0 → fini.

marque la fin du mot, cherche le début

end = i. Ensuite, tant que str[i] n'est pas un séparateur ET i >= 0, décrémente. À la sortie, le mot commence à i + 1.

write le mot + un espace si besoin

write(1, &str[i+1], end - i). Si c'est pas le dernier mot écrit, ajoute write(1, " ", 1) après.

boucle jusqu'à i < 0, puis newline

Tu recommences à l'étape 2. Quand tu sors de la boucle, write(1, "\n", 1). Fini.

String : "Wingardium Leviosa" · indexes 0 à 17. Un espace à l'index 10.

trace · rev_wstr "Wingardium Leviosa"
// start: len=18, i=17 ('a')
str[17] = 'a' → pas séparateur, word end = 17
walk back: str[16]='s', str[15]='o', ... str[11]='L'
str[10] = ' ' → STOP. word start = 11
write(1, &str[11], 17-10) → "Leviosa"
write(1, " ", 1) → (pas le premier mot imprimé? non, c'est le premier ici...)

// i = 10, skip séparateur
str[10] = ' ' → skip, i=9
str[9] = 'm' → pas séparateur, word end = 9
walk back: str[8]='u', ... str[0]='W'
i = -1 → STOP. word start = 0
write(1, " ", 1) → espace AVANT le prochain mot

les pièges à pas oublier.

Le sujet est piégeux côté edge cases. Lis bien ces 4 points.

./rev_wstr → \n
Pas d'argument ou plus d'un arg → juste un newline. Règle : argc != 2.
"abc" → abc
Un seul mot → juste ce mot + newline. Pas d'espace.
"a\tb" → b a
Les \t sont aussi séparateurs. Teste les deux (' ' ET '\t').
"hi bye" → bye hi
Séparateur entre mots = un seul espace en sortie, peu importe l'input.

le piège de write.

Pas de printf, pas de puts, pas de strlen. Les fonctions autorisées : write, malloc, free. C'est tout.

✦ rappel ✦

Signature : write(int fd, const void *buf, size_t count)

fd = 1 (stdout). buf = un pointeur vers les bytes à écrire. count = combien de bytes. Tu écris des bouts de la string originale, pas besoin de copier.

// un seul char
write(1, "\n", 1);
write(1, " ", 1);

// un segment de la string originale
// &str[start] = adresse du char n°start
// end - start + 1 = longueur du mot
write(1, &str[start], end - start + 1);
