rev_wstr
quick recap ↓

Inverser l'ordre des mots. Parcours backwards, une seule passe, zéro malloc.

🎯 l'algo en 4 gestes
  1. Aller à la fin : while (str[i]) i++; puis i--; → position du dernier char.
  2. Outer while : tant que i >= 0, traite un mot par tour.
  3. Dans le tour : end = i, recule tant que pas séparateur, write le mot [i+1 .. end].
  4. Espace entre mots : if (i >= 0) write(" ", 1) — pas d'espace quand i=-1 (dernier mot imprimé). i-- pour passer devant le sep.
💾 code final
#include <unistd.h> int main(int argc, char **argv) { char *str = argv[1]; int i = 0; int end = 0; if (argc != 2) { write(1, "\n", 1); return (0); } while (str[i]) i++; i--; while (i >= 0) { end = i; while (i >= 0 && str[i] != ' ' && str[i] != '\t') i--; write(1, &str[i + 1], end - i); if (i >= 0) write(1, " ", 1); i--; } write(1, "\n", 1); return (0); }
🎨 patterns clés
  • Write segments directs : zéro malloc. Tu donnes &str[i+1] + longueur end - i à write.
  • i ne fait que descendre : garantit zéro boucle infinie. Chaque tour décrémente de 1+ position.
  • Le walk-back s'arrête SUR le séparateur (ou à -1). Le i-- de fin de tour passe devant.
  • Espace conditionnel : if (i >= 0) write(" ") → évite trailing space quand on a fini le dernier mot.
  • argc != 2 : contrairement à rostring (qui accepte argc≥2), rev_wstr veut exactement 1 arg.
⚠️ les pièges
  • Bounds dans le walk-back : while (i >= 0 && str[i] != ' ' && str[i] != '\t') — sans le i >= 0, tu peux déréférencer str[-1].
  • Séparateurs = ' ' ET '\t' : toujours tester les deux.
  • Le if (i >= 0) avant write(" ") : évite trailing space. i = -1 signifie qu'on vient d'imprimer le dernier mot.
  • Longueur write : end - i (pas end - i + 1). Parce que i pointe sur le sep (ou -1), pas sur le 1er char du mot. Le 1er char est à i+1.
  • Input garanti "propre" : le sujet garantit pas de leading/trailing spaces et 1 seul espace entre mots. Donc pas besoin de collapser comme dans rostring.
🪞 différence avec rostring
  • rev_wstr : inverse TOUS les mots. Parcourt à l'envers.
  • rostring : déplace SEUL le premier mot à la fin. Parcourt à l'endroit.
  • rev_wstr input propre (1 seul espace garanti). Pas de collapse nécessaire.
  • rostring input peut être sale (multi-spaces, leading, trailing). Collapse obligatoire.
  • rev_wstr argc != 2. rostring argc < 2.
la règle d'or :
i ne fait que descendre → impossible de boucler.
write des segments, jamais de copie.
