rostring
quick recap ↓

Premier mot → à la fin. Collapse multi-spaces en 1. Pas de malloc, que du write.

🎯 l'algo en 3 étapes
  1. Step 1 : skip leading seps, mémorise start et end du 1er mot.
  2. Step 2 : boucle sur les mots restants. Flag printed : espace AVANT chaque mot sauf le 1er.
  3. Step 3 : espace (si printed) + write le 1er mot via [start..end] + '\n'.
💾 code final
#include <unistd.h> int main(int argc, char **argv) { int i = 0; char *str; int start; int end; int w_start; int printed = 0; if (argc < 2) { write(1, "\n", 1); return (0); } str = argv[1]; /* ═══ STEP 1 : bornes du premier mot ═══ */ while (str[i] == ' ' || str[i] == '\t') i++; start = i; while (str[i] && str[i] != ' ' && str[i] != '\t') i++; end = i; /* ═══ STEP 2 : write tous les mots après le premier ═══ */ while (str[i]) { while (str[i] == ' ' || str[i] == '\t') i++; if (str[i]) { if (printed) write(1, " ", 1); w_start = i; while (str[i] && str[i] != ' ' && str[i] != '\t') i++; write(1, &str[w_start], i - w_start); printed = 1; } } /* ═══ STEP 3 : premier mot à la fin ═══ */ if (printed) write(1, " ", 1); write(1, &str[start], end - start); write(1, "\n", 1); return (0); }
🎨 patterns clés à retenir
  • Flag "printed" : if (printed) write(" ") → chaque mot est précédé d'un espace sauf le 1er. Évite les trailing spaces.
  • Write segments directs : zéro malloc, tu donnes juste &str[w_start] + longueur à write.
  • Skip multi-seps : le while (str[i] == ' ' || ...) mange TOUS les espaces/tabs d'affilée → collapse natif.
  • Pas de check str[i] dans skip-sep : le \0 n'est ni ' ' ni '\t' → sort tout seul.
  • Check str[i] && dans walk-word : si on oublie, on dépasse le \0.
⚠️ pièges à pas rater
  • argc < 2 et PAS argc != 2. Sinon ./rostring "first" "2" te retourne "\n" au lieu de "first".
  • Multi-spaces input : le sujet garantit pas 1 seul espace en input. Ton code doit collapse (le pattern ci-dessus le fait naturellement).
  • Tabs comme séparateurs : toujours tester ' ' ET '\t'.
  • Le if (str[i]) après skip-sep : sans lui, tu risques de write un espace en trop quand le skip a été jusqu'à la fin.
  • Trailing spaces input (ex: "abc ") : step 2 tourne à vide, printed reste 0, step 3 n'ajoute pas d'espace avant le 1er mot. ✓
la règle d'or :
chaque mot est PRÉCÉDÉ d'un espace, sauf le tout premier.
jamais trailing, jamais double.
