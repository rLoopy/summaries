⚡ La règle OR vs AND — une fois pour toutes

Tu veux tester si un char est un espace ou un tab ?
Cas 1 — Tu veux "C'EST"
==   ||   ==
"C'est un espace OU un tab"
(au moins un des deux vrai)
while skip whitespace :
c == ' ' || c == '\t'
Cas 2 — Tu veux "C'EST PAS"
!=   &&   !=
"C'est ni un espace NI un tab"
(les deux faux)
while dans un mot :
c != ' ' && c != '\t'
Quand t'as == → utilise ||
Quand t'as != → utilise &&

🔧 Les 4 boucles, une par une

1

Aller à la fin de la string

Placer i sur le dernier caractère (avant \0)

while (argv[1][i])
    i++;
i--; // reculer sur le dernier char
On avance i jusqu'à trouver le \0. Puis on recule d'un cran pour être sur le dernier char de la string. C'est comme trouver la taille (strlen) et se positionner à la fin.
2

Skip les espaces de la fin

Reculer tant qu'on EST sur un espace ou tab

while (i >= 0 && (argv[1][i] == ' ' || argv[1][i] == '\t'))
    i--;
On SKIP les espaces → donc on veut que ce SOIT un espace ou un tab → == avec ||.

Le i >= 0 en premier empêche de sortir de la string si elle est vide ou que des espaces.
3

Reculer jusqu'au début du mot

Reculer tant qu'on N'EST PAS sur un espace/tab

while (i >= 0 && argv[1][i] != ' ' && argv[1][i] != '\t')
    i--;
i++; // on a trop reculé d'un cran, on corrige
On cherche le début du mot → donc on continue tant que ce N'EST PAS un espace ni un tab → != avec &&.

À la fin, i est avant le premier char du mot (sur un espace ou -1), donc on fait i++ pour atterrir sur le premier char.
4

Afficher le mot

Avancer tant qu'on est DANS le mot

while (argv[1][i] && argv[1][i] != ' ' && argv[1][i] != '\t')
{
    write(1, &argv[1][i], 1);
    i++;
}
write(1, "\n", 1);
On affiche char par char tant qu'on est dans le mot → même règle != avec &&.

Le argv[1][i] seul en premier vérifie qu'on est pas au \0 (fin de string).

✅ Le code complet

#include <unistd.h>

int main(int argc, char **argv)
{
    int i = 0;

    if (argc != 2)
    {
        write(1, "\n", 1);
        return (0);
    }
    // 1. aller à la fin
    while (argv[1][i])
        i++;
    i--;
    // 2. skip espaces de fin (== || ==)
    while (i >= 0 && (argv[1][i] == ' ' || argv[1][i] == '\t'))
        i--;
    // 3. reculer jusqu'au début du mot (!= && !=)
    while (i >= 0 && argv[1][i] != ' ' && argv[1][i] != '\t')
        i--;
    i++;
    // 4. afficher le mot
    while (argv[1][i] && argv[1][i] != ' ' && argv[1][i] != '\t')
    {
        write(1, &argv[1][i], 1);
        i++;
    }
    write(1, "\n", 1);
}
