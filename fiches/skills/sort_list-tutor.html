Bubble sort sur liste chaînée, pas à pas. cmp = ascendant (return (a <= b)) pour tous les exemples. On swap ->data, les nœuds ne bougent jamais.

🧠 Ce que fait ce code à chaque passe

  1. swapped = 0 : hypothèse "rien ne bougera cette passe". Un swap la remettra à 1.
  2. cur = lst : le pointeur repart au début de la liste.
  3. Inner : tant que cur->next existe, compare cur->data et cur->next->data.
  4. Si !cmp(a, b) → swap des data via tmp. Les ->next ne sont JAMAIS modifiés.
  5. cur = cur->next toujours, swap ou pas.
🎯 Parce qu'on swap les data, la tête lst ne bouge jamais → return (lst); simple.
