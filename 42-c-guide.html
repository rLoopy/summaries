Concept
Variables et types

Une variable est une boite avec un nom qui stocke une valeur en memoire. En C, il faut toujours declarer le type de la boite avant de l'utiliser.

Analogie
Imagine des boites de rangement. Un int est une grande boite pour des nombres entiers. Un char est une toute petite boite pour une seule lettre. Tu ne peux pas mettre un frigo dans une boite a chaussures.
types.c
int i = 0; // entier : -2147483648 a 2147483647 char c = 'A'; // un caractere (1 octet, 0 a 127) unsigned int n = 42; // entier positif uniquement char *str = "hello"; // pointeur vers une chaine long big = 9999999; // entier plus grand
Piege
Un char non-signe va de 0 a 255, mais un char signe va de -128 a 127. Si tu ecris char c = 200;, le resultat sera negatif ! Fais attention au type quand tu manipules des valeurs ASCII.

Concept
write() vs printf()

A 42, on utilise write() au lieu de printf(). Pourquoi ? Parce que printf est une fonction de haut niveau qui fait plein de choses en coulisses. write est un appel systeme direct au noyau — c'est la base.

write_demo.c
#include <unistd.h> // write(fd, buffer, nb_octets) // fd = 1 pour la sortie standard (le terminal) void ft_putchar(char c) { write(1, &c, 1); } void ft_putstr(char *str) { int i = 0; while (str[i]) { write(1, &str[i], 1); i++; } } void ft_putnbr(int n) { char c; if (n == -2147483648) { write(1, "-2147483648", 11); return ; } if (n < 0) { write(1, "-", 1); n = -n; } if (n >= 10) ft_putnbr(n / 10); c = (n % 10) + '0'; write(1, &c, 1); }
Piege
write(1, "a", 1) ecrit le caractere 'a'. Mais write(1, 'a', 1) est FAUX — les guillemets simples donnent un int, pas une adresse. Pour un char variable, utilise write(1, &c, 1) avec l'esperluette.
ft_putstr fizzbuzz all Level 1
Concept
Boucles while et conditions if/else

A 42, on utilise principalement while (jamais for a la norme). La boucle while repete un bloc tant que la condition est vraie (non-zero). Le if/else permet d'executer du code sous condition.

Analogie
Un while c'est comme un reveil qui sonne en boucle tant que tu ne l'eteins pas. Le if/else c'est un carrefour : tu tournes a gauche OU a droite selon le panneau.
while.c
// Afficher les chiffres 0 a 9 int i = 0; while (i < 10) { c = i + '0'; write(1, &c, 1); i++; } write(1, "\n", 1);
if_else.c
// FizzBuzz simplifie if (n % 15 == 0) write(1, "fb", 2); else if (n % 3 == 0) write(1, "f", 1); else if (n % 5 == 0) write(1, "b", 1); else ft_putnbr(n);
Piege
Oublier d'incrementer i++ dans un while = boucle infinie. Ton programme ne s'arretera jamais. Autre piege : ecrire if (n = 5) au lieu de if (n == 5) — le premier est une assignation (toujours vraie), pas une comparaison !
Concept
Fonctions

Une fonction est un bloc de code reutilisable. Elle a un type de retour, un nom, des parametres, et un corps. Si elle ne retourne rien, son type est void.

fonctions.c
// Prototype : type nom(params); int ft_strlen(char *str); // Implementation int ft_strlen(char *str) { int i = 0; while (str[i]) i++; return (i); } // Fonction void (ne retourne rien) void ft_swap(int *a, int *b) { int tmp; tmp = *a; *a = *b; *b = tmp; }
Piege
Pour ft_swap, on passe des pointeurs (int *a), pas des valeurs. Si tu passes des int normaux, la fonction modifie des copies et rien ne change dans le main ! C'est le piege n1 des debutants.
ft_swap ft_strlen ft_putstr
Concept
Chaines de caracteres

En C, une chaine est juste un tableau de char termine par un '\0' (le "null terminator", valeur 0). Quand tu fais while(str[i]), tu parcours jusqu'a ce '\0'.

ft_strcpy.c
char *ft_strcpy(char *dest, char *src) { int i = 0; while (src[i]) { dest[i] = src[i]; i++; } dest[i] = '\0'; return (dest); }
Piege
TOUJOURS terminer tes chaines par '\0' ! Si tu copies une chaine sans ajouter le null-terminator, tout ce qui vient apres en memoire sera lu comme faisant partie de ta chaine. Resultat : des caracteres poubelle a l'affichage.

Concept
argc / argv

Quand tu lances ./prog hello world, le systeme passe les arguments a ton main. argc = nombre d'arguments (ici 3), argv = tableau de chaines (argv[0]="./prog", argv[1]="hello", argv[2]="world").

main_args.c
int main(int argc, char **argv) { if (argc != 2) { write(1, "\n", 1); return (0); } ft_putstr(argv[1]); write(1, "\n", 1); return (0); }
Piege
Si l'exo attend 2 arguments et l'user en donne 0, il faut juste ecrire "\n" et quitter proprement. Toujours verifier argc en premier ! Et rappelle-toi : argv[1][0] est le premier caractere du premier argument, pas la chaine entiere.

Concept
Arithmetique de caracteres et ASCII

Chaque caractere est un nombre dans la table ASCII. 'A' = 65, 'a' = 97, '0' = 48. La difference entre majuscule et minuscule est toujours 32. On peut donc faire des maths sur les caracteres !

Char | Dec | Hex Char | Dec | Hex ─────┼─────┼──── ─────┼─────┼──── '0' | 48 | 0x30 'A' | 65 | 0x41 '9' | 57 | 0x39 'Z' | 90 | 0x5A ' ' | 32 | 0x20 'a' | 97 | 0x61 '\n' | 10 | 0x0A 'z' | 122 | 0x7A '\0' | 0 | 0x00 '~' | 126 | 0x7E
char_math.c
// Convertir un chiffre char en int int n = c - '0'; // '7' - '0' = 55 - 48 = 7 // Convertir minuscule en majuscule char upper = c - 32; // 'a' - 32 = 97 - 32 = 65 = 'A' // ROT13 : decaler de 13 dans l'alphabet if (c >= 'a' && c <= 'z') c = (c - 'a' + 13) % 26 + 'a'; // Verifier si c'est un chiffre if (c >= '0' && c <= '9') // c est un chiffre // repeat_alpha : 'a' se repete 1x, 'b' 2x, 'z' 26x int count = c - 'a' + 1; // 'c' - 'a' + 1 = 3
Piege
Pour ROT13/ROT1, attention au wrap-around ! Apres 'z' on revient a 'a'. La formule (c - 'a' + N) % 26 + 'a' gere ca automatiquement. N'oublie pas de traiter majuscules et minuscules separement.

Concept cle
Pointeurs en profondeur

Un pointeur est une variable qui stocke une adresse memoire. Quand tu ecris int *p = &x, p contient l'adresse de x, et *p te donne la valeur stockee a cette adresse.

Analogie
Imagine la memoire comme un immeuble. Chaque appartement a un numero (l'adresse). Un pointeur, c'est un papier ou tu as ecrit le numero d'un appartement. Avec ce papier tu peux aller visiter l'appartement (*p) ou juste lire le numero (p).
pointeurs.c
int x = 42; int *p = &x; // p pointe vers x printf("%d\n", *p); // 42 — dereferencement *p = 100; // x vaut maintenant 100 // Pointeur de pointeur (double pointeur) int **pp = &p; // pp pointe vers p **pp = 200; // x vaut maintenant 200 // Arithmetique de pointeurs int tab[] = {10, 20, 30}; int *ptr = tab; // tab est deja une adresse // *(ptr + 1) == tab[1] == 20 // ptr++ avance de sizeof(int) = 4 octets
Piege
Ne jamais dereferencer un pointeur NULL : *NULL = segfault garanti. Verifie toujours if (ptr != NULL) ou if (ptr) avant d'utiliser *ptr. Autre piege : confondre p++ (avance le pointeur) et (*p)++ (incremente la valeur pointee).
ft_strdup ft_strrev ft_swap
Concept cle
malloc / free

malloc demande au systeme de la memoire sur le heap (le tas). Contrairement aux variables locales (sur la stack), cette memoire persiste jusqu'a ce que tu la liberes avec free.

Analogie
malloc c'est comme louer un box de stockage. Tu demandes la taille dont tu as besoin, on te donne une clef (le pointeur). Quand tu n'en as plus besoin, tu rends la clef (free). Si tu perds la clef sans rendre le box, c'est un memory leak.
ft_strdup.c
#include <stdlib.h> char *ft_strdup(char *src) { int i = 0; int len = 0; char *res; while (src[len]) len++; res = (char *)malloc(sizeof(char) * (len + 1)); if (!res) return (NULL); while (src[i]) { res[i] = src[i]; i++; } res[i] = '\0'; return (res); }
Piege
Toujours allouer +1 pour le '\0' ! malloc(len) au lieu de malloc(len + 1) = buffer overflow. Et toujours verifier si malloc retourne NULL (plus de memoire). Dans l'exam, ne pas free ne te penalisera pas, mais c'est une mauvaise habitude.
Concept
Operations bitwise

Les operations bit-a-bit manipulent les bits individuels d'un nombre. Chaque int est compose de 32 bits (0 ou 1). Tres utile pour print_bits, reverse_bits, swap_bits et is_power_of_2.

Operateur | Nom | Exemple (8 bits) ──────────┼────────────┼────────────────── & | AND | 1100 & 1010 = 1000 | | OR | 1100 | 1010 = 1110 ^ | XOR | 1100 ^ 1010 = 0110 ~ | NOT | ~1100 = 0011 << | Shift left | 0001 << 3 = 1000 >> | Shift right| 1000 >> 2 = 0010
bitwise.c
// print_bits : afficher les 8 bits d'un octet void print_bits(unsigned char octet) { int i = 7; while (i >= 0) { char c = ((octet >> i) & 1) + '0'; write(1, &c, 1); i--; } } // reverse_bits : inverser l'ordre des bits unsigned char reverse_bits(unsigned char octet) { unsigned char res = 0; int i = 0; while (i < 8) { res = (res << 1) | (octet & 1); octet >>= 1; i++; } return (res); } // is_power_of_2 : astuce elegante int is_power_of_2(unsigned int n) { return (n != 0 && (n & (n - 1)) == 0); } // 8 = 1000, 7 = 0111 → 1000 & 0111 = 0000 → true!
Piege
Le bit de poids fort est a gauche (indice 7), le bit de poids faible a droite (indice 0). Pour print_bits, parcours de 7 a 0 (decroissant). Pour swap_bits, le nibble haut ce sont les bits 4-7, le nibble bas les bits 0-3.
Concept cle
Reproduire les fonctions de la libc

L'exam te demandera de recoder des fonctions standard. Voici les plus importantes avec leurs subtilites.

ft_atoi.c
int ft_atoi(char *str) { int i = 0; int sign = 1; int res = 0; while (str[i] == ' ' || str[i] == '\t') i++; if (str[i] == '-' || str[i] == '+') { if (str[i] == '-') sign = -1; i++; } while (str[i] >= '0' && str[i] <= '9') { res = res * 10 + (str[i] - '0'); i++; } return (res * sign); }
ft_strcmp.c
int ft_strcmp(char *s1, char *s2) { int i = 0; while (s1[i] && s1[i] == s2[i]) i++; return ((unsigned char)s1[i] - (unsigned char)s2[i]); } // strcmp retourne : // 0 si egal // < 0 si s1 < s2 // > 0 si s1 > s2
ft_strrev.c
char *ft_strrev(char *str) { int i = 0; int j = 0; char tmp; while (str[j]) j++; j--; while (i < j) { tmp = str[i]; str[i] = str[j]; str[j] = tmp; i++; j--; } return (str); }
ft_strcspn.c
// Longueur du prefixe de s qui // ne contient AUCUN char de reject size_t ft_strcspn(char *s, char *reject) { int i = 0; int j; while (s[i]) { j = 0; while (reject[j]) { if (s[i] == reject[j]) return (i); j++; } i++; } return (i); }
Piege
Dans ft_atoi, on skip les espaces ET les tabs en debut. On gere UN seul signe (+/-). On s'arrete au premier non-chiffre. Pour ft_strcmp, le cast en unsigned char est crucial pour eviter des resultats negatifs inattendus avec des caracteres > 127.

// Afficher les chars de s1 puis s2, sans doublon int main(int argc, char **argv) { int seen[256] = {0}; int i = 0; if (argc == 3) { while (argv[1][i]) { if (!seen[(unsigned char)argv[1][i]]) { seen[(unsigned char)argv[1][i]] = 1; write(1, &argv[1][i], 1); } i++; } i = 0; while (argv[2][i]) { if (!seen[(unsigned char)argv[2][i]]) { seen[(unsigned char)argv[2][i]] = 1; write(1, &argv[2][i], 1); } i++; } } write(1, "\n", 1); return (0); }

Concept cle
Algorithmes mathematiques

L'exam Level 3 adore les maths : PGCD, PPCM, nombres premiers, somme de premiers. Voici les formules cles.

PGCD — Euclide
Le PGCD de deux nombres, c'est le plus grand nombre qui divise les deux. L'algorithme d'Euclide : on remplace le plus grand par le reste de la division, jusqu'a ce que le reste soit 0.
pgcd.c
// PGCD iteratif (Euclide) int pgcd(int a, int b) { int tmp; while (b != 0) { tmp = b; b = a % b; a = tmp; } return (a); } // PPCM a partir du PGCD // lcm(a, b) = (a * b) / gcd(a, b)
Nombres premiers
Un nombre premier est divisible uniquement par 1 et lui-meme. Pour verifier, on teste les diviseurs de 2 a la racine carree du nombre. Si aucun ne divise, c'est premier.
primes.c
int is_prime(int n) { int i = 2; if (n < 2) return (0); while (i * i <= n) { if (n % i == 0) return (0); i++; } return (1); } // add_prime_sum : somme des // premiers <= n
Piege
Pour pgcd, l'exam passe les arguments en string via argv. Il faut les convertir avec atoi. Si argc != 3, afficher "\n". Pour is_prime, utilise i * i <= n au lieu de i <= sqrt(n) pour eviter d'inclure math.h.
Concept
Conversion de base

Convertir un nombre decimal en hexadecimal ou en base N. Le principe : diviser par la base et collecter les restes.

print_hex.c
void print_hex(int n) { char *base = "0123456789abcdef"; if (n >= 16) print_hex(n / 16); write(1, &base[n % 16], 1); } // ft_atoi_base : string en base N vers int int ft_atoi_base(char *str, int base) { int res = 0; int i = 0; int digit; while (str[i]) { if (str[i] >= '0' && str[i] <= '9') digit = str[i] - '0'; else if (str[i] >= 'a' && str[i] <= 'f') digit = str[i] - 'a' + 10; else if (str[i] >= 'A' && str[i] <= 'F') digit = str[i] - 'A' + 10; else break ; res = res * base + digit; i++; } return (res); }
Piege
Pour print_hex, la recursion affiche les chiffres dans le bon ordre (les plus significatifs en premier). Si tu fais une boucle iterative, les chiffres sortent a l'envers ! La recursion est la methode la plus simple ici.
Concept cle
Listes chainees

Une liste chainee est une suite de noeuds. Chaque noeud contient une valeur et un pointeur vers le noeud suivant. Le dernier pointe vers NULL.

Analogie
Imagine un train : chaque wagon (noeud) a un contenu (passagers/data) et un accrochage vers le wagon suivant (pointeur next). Le dernier wagon n'est accroche a rien (NULL).
linked_list.c
// La structure d'un noeud typedef struct s_list { void *data; struct s_list *next; } t_list; // Compter les elements (ft_list_size) int ft_list_size(t_list *begin_list) { int count = 0; while (begin_list) { count++; begin_list = begin_list->next; } return (count); } // Appliquer une fonction a chaque element void ft_list_foreach(t_list *begin, void (*f)(void *)) { while (begin) { f(begin->data); begin = begin->next; } }
Piege
L'exam fournit la structure t_list dans l'enonce — tu n'as pas a la definir toi-meme. Le champ data est un void * : il peut pointer vers n'importe quel type. Pour avancer, c'est node = node->next, pas node++ (ce n'est pas un tableau !).

Manipulation avancee de chaines

Les exos Level 3 demandent souvent de nettoyer des espaces ou de capitaliser des mots. La cle : savoir detecter les transitions entre espaces et non-espaces.

epur_str.c
// " hello world " → "hello world" int main(int argc, char **argv) { int i = 0; int space = 0; if (argc == 2) { while (argv[1][i] == ' ' || argv[1][i] == '\t') i++; while (argv[1][i]) { if (argv[1][i] == ' ' || argv[1][i] == '\t') space = 1; else { if (space) { write(1, " ", 1); space = 0; } write(1, &argv[1][i], 1); } i++; } } write(1, "\n", 1); return (0); }
str_capitalizer.c
// Capitaliser le debut de chaque mot // "hello world" → "Hello World" void capitalize(char *str) { int i = 0; while (str[i]) { // Debut de mot : debut de chaine // ou char apres espace/tab if (str[i] >= 'a' && str[i] <= 'z' && (i == 0 || str[i - 1] == ' ' || str[i - 1] == '\t')) str[i] -= 32; else if (str[i] >= 'A' && str[i] <= 'Z' && i > 0 && str[i - 1] != ' ' && str[i - 1] != '\t') str[i] += 32; write(1, &str[i], 1); i++; } }
ft_range.c
// Creer un tableau d'int de start a end (exclu) int *ft_range(int start, int end) { int len; int *res; int i = 0; len = end - start; if (len < 0) len = -len; res = (int *)malloc(sizeof(int) * len); if (!res) return (NULL); while (i < len) { if (start < end) res[i] = start + i; else res[i] = start - i; i++; } return (res); }
Piege
Pour epur_str, le piege est les espaces de fin de chaine. Avec le flag space, on n'ecrit l'espace que quand un nouveau mot suit — ca evite le trailing space. Pour rstr_capitalizer, c'est la derniere lettre de chaque mot qui est capitalisee (pas la premiere).

hidenp — technique deux pointeurs

Verifier si les chars de s1 apparaissent dans l'ordre dans s2. La technique deux pointeurs : un curseur sur s1, un sur s2. Quand on match, on avance s1. On avance toujours s2.

hidenp.c
// "ace" dans "abcdef" → 1 (oui) // "aec" dans "abcdef" → 0 (non, pas dans l'ordre) int main(int argc, char **argv) { int i = 0; int j = 0; if (argc == 3) { while (argv[1][i] && argv[2][j]) { if (argv[1][i] == argv[2][j]) i++; j++; } if (!argv[1][i]) write(1, "1", 1); else write(1, "0", 1); } write(1, "\n", 1); return (0); }

Concept cle
Recursion avancee et Flood Fill

La recursion, c'est une fonction qui s'appelle elle-meme. Chaque appel resout un sous-probleme plus petit jusqu'a atteindre un cas de base (condition d'arret). Le flood fill est un algorithme recursif qui "remplit" une zone a partir d'un point.

Analogie
Imagine que tu cherches tes clefs dans un immeuble. Tu demandes au gardien du 1er etage. Il ne les a pas, alors il demande au gardien du 2e, qui demande au 3e... jusqu'a ce qu'un gardien les trouve (cas de base) et les passe a celui d'en dessous, etc.
flood_fill.c
typedef struct s_point { int x; int y; } t_point; void fill(char **tab, t_point size, t_point cur, char target) { // Cas de base : hors limites ou pas la bonne couleur if (cur.x < 0 || cur.x >= size.x || cur.y < 0 || cur.y >= size.y) return ; if (tab[cur.y][cur.x] != target) return ; // Remplir le pixel courant tab[cur.y][cur.x] = 'F'; // Remplir les 4 voisins fill(tab, size, (t_point){cur.x - 1, cur.y}, target); fill(tab, size, (t_point){cur.x + 1, cur.y}, target); fill(tab, size, (t_point){cur.x, cur.y - 1}, target); fill(tab, size, (t_point){cur.x, cur.y + 1}, target); } void flood_fill(char **tab, t_point size, t_point begin) { char target = tab[begin.y][begin.x]; if (target == 'F') return ; fill(tab, size, begin, target); }
Piege
Dans flood_fill, on modifie la cellule AVANT de recurser. Sinon on tombe dans une boucle infinie (A appelle B, B appelle A...). L'exam donne les structs t_point dans l'enonce. Attention : tab[y][x], pas tab[x][y] !
Concept
Pointeurs de fonction

Un pointeur de fonction stocke l'adresse d'une fonction. Ca permet de passer une fonction en parametre d'une autre — tres utile pour trier ou appliquer une operation a chaque element.

func_ptr.c
// Syntaxe : type_retour (*nom)(params) int (*cmp)(int, int); // Exemple : fonction comparateur int ascending(int a, int b) { return (a - b); } // sort_list utilise un comparateur t_list *sort_list(t_list *lst, int (*cmp)(int, int)) { int swapped = 1; t_list *cur; void *tmp; while (swapped) { swapped = 0; cur = lst; while (cur->next) { if (cmp(*(int *)cur->data, *(int *)cur->next->data) > 0) { tmp = cur->data; cur->data = cur->next->data; cur->next->data = tmp; swapped = 1; } cur = cur->next; } } return (lst); }
Piege
La syntaxe du pointeur de fonction est dure a memoriser : int (*f)(int, int). Les parentheses autour de *f sont obligatoires ! Sans elles, int *f(int, int) declare une fonction qui retourne un int *. Pour sort_list, on swap les data, pas les noeuds.
Exercice cle
ft_split — malloc 2D

L'exercice le plus difficile de l'exam. Il faut decouper une chaine en un tableau de chaines (tableau 2D) en se basant sur un ou plusieurs separateurs.

Analogie
Imagine une phrase ecrite sur un ruban. ft_split coupe le ruban a chaque espace et met chaque morceau dans une enveloppe separee. Le resultat est une pile d'enveloppes (le tableau de chaines).
ft_split.c
#include <stdlib.h> static int is_sep(char c) { return (c == ' ' || c == '\t' || c == '\n'); } static int count_words(char *str) { int count = 0; int i = 0; while (str[i]) { while (str[i] && is_sep(str[i])) i++; if (str[i]) count++; while (str[i] && !is_sep(str[i])) i++; } return (count); } static char *get_word(char *str, int start, int end) { char *word; int i = 0; word = (char *)malloc(sizeof(char) * (end - start + 1)); if (!word) return (NULL); while (start < end) { word[i] = str[start]; i++; start++; } word[i] = '\0'; return (word); } char **ft_split(char *str) { char **res; int i = 0; int j = 0; int start; res = (char **)malloc(sizeof(char *) * (count_words(str) + 1)); if (!res) return (NULL); while (str[i]) { while (str[i] && is_sep(str[i])) i++; if (str[i]) { start = i; while (str[i] && !is_sep(str[i])) i++; res[j] = get_word(str, start, i); j++; } } res[j] = NULL; return (res); }
Piege
Le tableau final doit se terminer par NULL (c'est res[j] = NULL a la fin). N'oublie pas le +1 dans le malloc du tableau de pointeurs. Les separateurs de l'exam sont souvent espaces + tabs + newlines. Lis bien l'enonce !

// Supprimer les noeuds ou // data == data_ref void ft_list_remove_if(t_list **begin, void *data_ref, int (*cmp)(void *, void *)) { t_list *tmp; if (!begin || !*begin) return ; if (cmp((*begin)->data, data_ref) == 0) { tmp = *begin; *begin = (*begin)->next; free(tmp); ft_list_remove_if(begin, data_ref, cmp); } else ft_list_remove_if(&(*begin)->next, data_ref, cmp); }

Pour fprime, ne pas incrementer div apres avoir divise — on peut avoir le meme facteur plusieurs fois (ex: 8 = 2*2*2). Exercice 1 — ft_recursive_power
Ecris int ft_recursive_power(int base, int power) qui calcule base elevee a la puissance power de maniere recursive. Cas de base : power == 0 retourne 1. Si power < 0, retourne 0.
Exercice 2 — ft_apply_to_array
Ecris void ft_apply_to_array(int *tab, int size, void (*f)(int)) qui applique la fonction f a chaque element du tableau. Teste avec une fonction qui affiche chaque nombre suivi d'un espace.
Exercice 3 — ft_join_words
Ecris char *ft_join_words(char **words, int count, char sep) qui joint un tableau de chaines en une seule, separees par sep. Utilise malloc. Exemple : {"hello", "world"} avec sep '-' donne "hello-world".
