print_bits.c 
#include <unistd.h>

void	print_bits(unsigned char octet)
{
	int		i = 8;
	char	c;

	while (i--)
	{
		c = ((octet >> i) & 1) + '0';
		write(1, &c, 1);
	}
}

Flashcards

Réponds dans ta tête AVANT de cliquer

+
Combien de bits dans un unsigned char ?
1 octet...

8 bits. Chaque bit vaut 0 ou 1. Valeurs décimales par position : 128, 64, 32, 16, 8, 4, 2, 1. Donc un unsigned char va de 0 à 255.

+
Que fait octet >> i ?
Right shift...

Décale l'octet de i positions vers la droite. Le bit qui était en position i se retrouve en position 0 (tout à droite). Les bits qui débordent sont perdus, les nouveaux bits à gauche sont des zéros.

+
Pourquoi & 1 après le shift ?
Masque...

1 en binaire = 00000001. Le AND avec 1 isole le bit de position 0 (tout à droite). Résultat : soit 0, soit 1, rien d'autre. C'est l'étape "j'extrais la réponse".

+
Pourquoi + '0' avant le write ?
ASCII vs nombre...

0 et 1 sont des nombres, pas des caractères affichables. En ASCII : '0' = 48, '1' = 49. Donc 0 + '0' = '0' et 1 + '0' = '1'. Sans ça, write afficherait des caractères de contrôle invisibles.

+
Pourquoi while (i--) démarre à 8, pas 7 ?
Post-décrément...

i-- est un post-décrément : l'expression vaut l'ANCIENNE valeur de i, puis décrémente. Avec i = 8 : check 8 (vrai), i devient 7, le body utilise i = 7. Dernier tour : check 1 (vrai), i = 0, body avec 0. Total : 8 itérations, bits 7→0. Avec i = 7, on ne fait que 7 tours et on rate le bit de poids fort.

Pièges déjoués

4 pièges — chaque carte = une leçon gravée

POST-DÉCRÉMENT
PIÈGE #1
✕int i = 7; while (i--) { ... }
✓int i = 8; while (i--) { ... }
Le piège : i-- renvoie l'ANCIENNE valeur de i, puis décrémente. Avec i=7, le check passe 7 fois seulement → on rate le bit de poids fort (bit 7 = 128). Borne sup stricte : i = 8.
CHAR VS INT
PIÈGE #2
✕c = (octet >> i) & 1; // 0 ou 1
✓c = ((octet >> i) & 1) + '0';
Le piège : sans + '0', on écrit les chars ASCII 0 et 1 (caractères de contrôle invisibles, pas les chiffres). Le '0' (48) est le décalage vers les chiffres affichables.
SIGNED CHAR
PIÈGE #3
✕void print_bits(char octet)
✓void print_bits(unsigned char octet)
Le piège : le sujet exige unsigned char. Avec un char signé, le right shift sur une valeur négative (bit de signe à 1) est défini par l'implémentation → comportement imprévisible. Toujours unsigned pour la manip bitwise.
ORDRE DES BITS
PIÈGE #4
✕i: 0 → 7 // print bit 0 en premier
✓i: 7 → 0 // print bit 7 (MSB) en premier
Le piège : on lit un binaire de gauche à droite = du bit de poids fort (MSB, position 7) au bit de poids faible (LSB, position 0). print_bits(2) doit donner 00000010, pas 01000000.

Pattern réutilisable

Shift & mask — extraire un bit précis d'un byte

  1. Shift : octet >> i amène le bit qu'on veut en position 0
  2. Mask : & 1 isole ce bit → résultat 0 ou 1
  3. Convert : + '0' transforme le nombre en char affichable
  4. Write : write(1, &c, 1) écrit un seul caractère
  5. Loop : répéter du bit 7 (MSB) au bit 0 (LSB)
PATTERN SHIFT & MASK
print_bits — lire le bit i, l'afficher
reverse_bits — lire bit i d'un côté, l'écrire à la position opposée avec |=
swap_bits — shift + OR pour combiner les 4 bits hauts et 4 bits bas
is_bit_set — (x >> i) & 1 pour tester un flag
Principe — shift ammène le bit, mask l'isole

Évolution du code

2 versions — de la forme classique à la forme condensée

VERSION 1 — forme classique (joker)
void print_bits(unsigned char octet) { int i = 7; char c; while (i >= 0) { c = ((octet >> i) & 1) + '0'; write(1, &c, 1); i--; } }
Lisible, pattern de boucle décroissante classique
i = 7 → 0, tous les bits couverts ✓
Un peu verbeux : 3 lignes pour la boucle (condition + body + i--)
VERSION FINALE — while (i--) ✓
void print_bits(unsigned char octet) { int i = 8; char c; while (i--) { c = ((octet >> i) & 1) + '0'; write(1, &c, 1); } }
Plus condensé : décrément intégré dans la condition
i = 8 pour compenser le post-décrément ✓
Dans le body, i vaut déjà 7, 6, 5... 0 ✓

Exercices de transfert

Même pattern, exo différent — solidifie l'apprentissage

CHALLENGE 1
reverse_bits
Inverser l'ordre des 8 bits d'un byte et retourner le résultat. Même shift & mask pour lire, mais on construit un nouveau byte avec |= et un shift opposé.
unsigned char reverse_bits(unsigned char octet);
// 00000010 (2) → 01000000 (64)
Indice : result |= ((octet >> i) & 1) << (7 - i);
CHALLENGE 2
swap_bits
Échanger les 4 bits hauts avec les 4 bits bas d'un byte. Pas de boucle, juste deux shifts et un OR.
unsigned char swap_bits(unsigned char octet);
// 11110000 → 00001111
Indice : (octet >> 4) | (octet << 4) — le shift "perd" les bits qui débordent.
CHALLENGE 3
Variante : print avec masque qui glisse
Refaire print_bits avec une approche alternative : un masque qui se décale au lieu de décaler l'octet. Équivalent en termes de résultat, différent en termes de raisonnement.
unsigned char mask = 128;
while (mask) { ... mask >>= 1; }
Indice : c = (octet & mask) ? '1' : '0'; — on teste si le masque matche.
