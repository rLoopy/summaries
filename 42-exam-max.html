Version validée — compile avec -Wall -Wextra -Werror, tous tests OK

max.c 
int  max(int* tab, unsigned int len)
{
    unsigned int i = 0;
    if (len == 0)
        return 0;
    int max = tab[i];
    while (i < len)
    {
        if (tab[i] > max)
            max = tab[i];
        i++;
    }
    return (max);
}

Pattern réutilisable

Parcours de tableau avec accumulateur — revient dans min, max, sum, search, count...

  1. Gérer le cas vide len == 0 en premier
  2. Initialiser l'accumulateur avec tab[0] — jamais avec 0
  3. Parcourir avec i < len — l'index, pas la valeur
  4. Comparer tab[i] avec l'accumulateur — pas avec tab[i+1]
  5. Return l'accumulateur

Mes erreurs

7 erreurs corrigées — chaque carte = une leçon à retenir

BOUCLE
ERREUR #1
✕while (tab[i])
✓while (i < len)
Règle : un tableau d'int ≠ une string. Pas de \0 à la fin. while(str[i]) = strings uniquement. Tableau → toujours i < len.
BOUCLE
ERREUR #2
✕while (tab[i] < len)
✓while (i < len)
Règle : tab[i] = la valeur dans la case. i = quelle case. On compare l'INDEX à la taille, pas la VALEUR.
LOGIQUE
ERREUR #3
✕max = tab[i]; (sans condition)
✓if (tab[i] > max) max = tab[i];
Règle : on update l'accumulateur SEULEMENT si le nouveau est meilleur. Sinon on écrase tout à chaque tour.
LOGIQUE
ERREUR #4
✕if (tab[i] < tab[i+1])
✓if (tab[i] > max)
Règle : toujours comparer avec l'accumulateur max, jamais entre éléments adjacents. tab[i+1] déborde au dernier élément.
INITIALISATION
ERREUR #5
✕int max = 0;
✓int max = tab[0];
Règle : avec {-5, -3, -1} et max=0, on retourne 0 qui n'est pas dans le tableau. Toujours initialiser avec le premier élément.
SÉCURITÉ
ERREUR #6
✕int max = tab[i]; // avant check
✓if (len == 0) return 0; // PUIS tab[i]
Règle : toujours vérifier les cas limites AVANT d'accéder aux données. Lire tab[0] sur un tableau vide = crash.
TYPE
ERREUR #7
✕int i = 0; comparé à unsigned int len
✓unsigned int i = 0;
Règle : -Wsign-compare + -Werror = compile pas. Si len est unsigned, le compteur aussi. Mais l'accumulateur reste int (pour les négatifs).
