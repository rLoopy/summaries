Trouver le plus grand int dans un tableau

SUBJECT.EN.TXT
int max(int* tab, unsigned int len); - tab = tableau d'int - len = nombre d'éléments - Retourne le plus grand nombre du tableau - Si le tableau est vide, retourne 0 - Allowed functions: None
✓
Code final
max.c
int  max(int* tab, unsigned int len)
{
    unsigned int i = 0;
    if (len == 0)
        return 0;
    int max = tab[i];
    while (i < len)
    {
        if (tab[i] > max)
            max = tab[i];
        i++;
    }
    return (max);
}
◆
Pattern réutilisable
🔄 Parcours de tableau avec accumulateur

Ce pattern revient dans : min, max, sum, search, count...

  1. Gérer le cas vide (len == 0) en premier
  2. Initialiser l'accumulateur avec tab[0]
  3. Parcourir avec i < len
  4. Comparer tab[i] avec l'accumulateur (pas avec tab[i+1])
  5. Return l'accumulateur
✕
Mes erreurs
BOUCLE
ERREUR #1
✕while (tab[i])
✓while (i < len)
Règle : un tableau d'int ≠ une string. Pas de \0 à la fin. Pour un tableau → toujours i < len. Le while(str[i]) c'est UNIQUEMENT pour les strings.
BOUCLE
ERREUR #2
✕while (tab[i] < len)
✓while (i < len)
Règle : tab[i] = la valeur dans la case. i = quelle case. On compare l'INDEX à la taille, pas la VALEUR.
LOGIQUE
ERREUR #3
✕max = tab[i]; (sans condition)
✓if (tab[i] > max) max = tab[i];
Règle : on update l'accumulateur SEULEMENT si le nouveau est meilleur. Sinon on écrase tout à chaque tour.
LOGIQUE
ERREUR #4
✕if (tab[i] < tab[i+1])
✓if (tab[i] > max)
Règle : toujours comparer avec l'accumulateur max, jamais entre éléments adjacents. En plus, tab[i+1] déborde quand i est au dernier élément.
INITIALISATION
ERREUR #5
✕int max = 0;
✓int max = tab[0];
Règle : avec {-5, -3, -1} et max=0, on retourne 0 qui n'est pas dans le tableau. Toujours initialiser avec le premier élément.
SÉCURITÉ
ERREUR #6
✕int max = tab[i]; // avant le check len==0
✓if (len == 0) return 0; // PUIS int max = tab[i];
Règle : toujours vérifier les cas limites AVANT d'accéder aux données. Sinon crash sur tableau vide.
TYPE
ERREUR #7
✕int i = 0; comparé à unsigned int len
✓unsigned int i = 0;
Règle : -Wsign-compare + -Werror = ça compile pas. Si len est unsigned, le compteur aussi. Mais l'accumulateur reste int.

  • ☐

  • ☐

  • ☐

  • ☐
