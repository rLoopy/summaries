inter.c 
#include <unistd.h>

int main(int argc, char **argv)
{
	if (argc != 3)
	{
		write(1, "\n", 1);
		return 0;
	}
	int i = 0;
	int j = 0;
	int dupe = 0;
	int in_s2 = 0;
	while (argv[1][i])
	{
		j = 0;
		dupe = 0;
		while (j < i)
		{
			if (argv[1][j] == argv[1][i])
				dupe = 1;
			j++;
		}
		j = 0;
		in_s2 = 0;
		while (argv[2][j])
		{
			if (argv[2][j] == argv[1][i])
				in_s2 = 1;
			j++;
		}
		if (dupe == 0 && in_s2 == 1)
			write(1, &argv[1][i], 1);
		i++;
	}
	write(1, "\n", 1);
	return 0;
}

Flashcards

Réponds dans ta tête AVANT de cliquer

+
Pourquoi 2 flags dans inter et pas 1 ?
2 conditions séparées...

On doit vérifier DEUX choses pour chaque char de s1 : (1) dupe = "déjà affiché avant dans s1 ?" et (2) in_s2 = "présent dans s2 ?". Combiner les deux dans un seul flag serait ambigu. Avec 2 flags, la condition d'écriture est claire : dupe == 0 && in_s2 == 1.

+
Pourquoi 1 seule phase (que s1) et pas 2 comme union ?
Ordre de sortie...

L'output sort dans l'ordre de s1 (le sujet). Les chars viennent tous de s1 (puisqu'ils doivent y être). On ne visite jamais s2 pour choisir quoi imprimer — s2 sert juste de "référence de présence". Donc un seul while principal sur s1 suffit.

+
Que fait la 2e boucle interne while (argv[2][j]) ?
Scan complet...

Elle parcourt toute s2 jusqu'au \0 en comparant chaque char avec argv[1][i] (le char courant de s1). Dès qu'elle trouve un match → in_s2 = 1. Le scan continue (pas de break), mais in_s2 reste à 1.

+
Et si argv[1][i] est dans s2 mais déjà print ?
Les deux flags...

Exemple : s1 = "aba", le 2e 'a'. in_s2 = 1 (s2 contient 'a') MAIS dupe = 1 (vu avant dans s1). La condition dupe == 0 && in_s2 == 1 échoue → skip. Les deux flags travaillent ensemble.

+
Différence avec union en une ligne ?
Union vs intersection...

union = "soit dans s1, soit dans s2" (OR logique, 2 phases). inter = "dans s1 ET dans s2" (AND logique, 1 phase). Symétriquement, la condition in_s2 dans inter est l'opposée de "passer le filtre" : dans union on écrit si PAS dans s1 ; dans inter on écrit si DANS s2.

Pièges déjoués

4 pièges — chaque carte = une leçon gravée

COMBINAISON
PIÈGE #1
✕if (dupe == 0 || in_s2 == 1) // OU
✓if (dupe == 0 && in_s2 == 1) // ET
Le piège : c'est un ET logique, pas un OU. On veut "pas doublon ET dans s2". Avec ||, on afficherait des chars soit non-dupliqués soit dans s2 → resultat incorrect.
RESET DES FLAGS
PIÈGE #2
✕// flags déclarés hors boucle, jamais reset
✓dupe = 0; ... in_s2 = 0; // AVANT chaque scan
Le piège : si in_s2 n'est pas remis à 0 au début de chaque tour externe, il reste à 1 une fois qu'il a flip → chaque char suivant est cru présent dans s2. Reset OBLIGATOIRE.
RESET DE j
PIÈGE #3
✕// j pas reset entre les 2 boucles internes
✓j = 0; // AVANT le 2ème while
Le piège : après la 1ère boucle interne, j peut être à n'importe quelle valeur. Sans reset, la 2ème boucle part d'une position incorrecte → scan s2 incomplet → in_s2 faux.
MAUVAISE STRING SCANNÉE
PIÈGE #4
✕if (argv[1][j] == argv[2][i]) // inversé !
✓if (argv[2][j] == argv[1][i]) // correct
Le piège : dans la 2e boucle interne, on cherche argv[1][i] (char courant de s1) dans s2, donc on compare avec argv[2][j]. Confusion facile quand on fatigue.
4

Pattern réutilisable

Multi-flag — plusieurs conditions combinées en &&

  1. argc != 3 → \n + return 0
  2. while argv[1][i] — pour chaque char de s1
  3. Reset dupe = 0, scan j < i dans s1 → dupe = 1 si trouvé
  4. Reset j = 0, in_s2 = 0, scan argv[2][j] entier → in_s2 = 1 si trouvé
  5. if (dupe == 0 && in_s2 == 1) → write le char
  6. Après le while principal → write \n
UNION vs INTER : comparatif
union — 2 phases (s1 + s2), 1 flag, OR logique
inter — 1 phase (s1 seul), 2 flags, AND logique
diff — 1 phase (s1), 2 flags, condition : dupe == 0 && in_s2 == 0
sym_diff — 2 phases, 2 flags (présence et doublon)
Pattern — un flag par condition indépendante, combinés en && ou || selon la logique

Évolution union → inter

Comment inter dérive d'union en une modif ciblée

DE UNION → INTER
// union : 2 phases + 1 flag 'found' // inter : 1 phase + 2 flags 'dupe' + 'in_s2' // 1) Supprimer la phase s2 entièrement // 2) Dans la phase s1, ajouter une 2ème boucle interne // qui scan s2 entier avec le flag 'in_s2' // 3) Changer la condition de write : // union : if (found == 0) // inter : if (dupe == 0 && in_s2 == 1)
Structure préservée (familier)
Changement ciblé sur la condition ✓
VERSION FINALE (joker)
int i = 0, j = 0; int dupe = 0, in_s2 = 0; while (argv[1][i]) { j = 0; dupe = 0; while (j < i) // boucle 1 : dupe ? { if (argv[1][j] == argv[1][i]) dupe = 1; j++; } j = 0; in_s2 = 0; while (argv[2][j]) // boucle 2 : in_s2 ? { if (argv[2][j] == argv[1][i]) in_s2 = 1; j++; } if (dupe == 0 && in_s2 == 1) write(1, &argv[1][i], 1); i++; } write(1, "\n", 1); return 0;

// "zpadinton" + "paqefwtdjety…" → "zpadintoqefwjy"
Indice : parcours s1 puis s2, flag found passé à 1 si déjà vu avant.
CHALLENGE 3
is_subset (généralisation)
Retourner 1 si tous les chars de s1 sont dans s2, 0 sinon. Utilise la 2e boucle interne d'inter (check in_s2), mais on return au premier char manquant.
int is_subset(char *s1, char *s2);
Indice : si un char de s1 n'est pas dans s2 → return 0 immédiatement. Sinon, après la boucle principale, return 1.
