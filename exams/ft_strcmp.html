int    ft_strcmp(char *s1, char *s2)
{
    int i = 0;
    while (s1[i] && s2[i])
    {
        if (s1[i] != s2[i])
            return (s1[i] - s2[i]);
        i++;
    }
    return (s1[i] - s2[i]);
}

Flashcards

Réponds dans ta tête AVANT de cliquer

+
strcmp retourne -1, 0 ou 1 ?
Pas exactement...

Non ! strcmp retourne la différence entre les premiers caractères qui diffèrent : s1[i] - s2[i]. Le signe indique le résultat, mais la valeur peut être -32, 104, etc. Certaines impls retournent -1/0/1 mais ce n'est pas garanti.

+
Pourquoi s1[i] && s2[i] et pas juste s1[i] ?
Que se passe-t-il si s2 est plus courte ?

Si on ne vérifie que s1[i], on continue à lire s2 après son \0 si s1 est plus longue. Il faut s'arrêter dès que l'une des deux strings est terminée.

+
Pourquoi retourner s1[i] - s2[i] après la boucle et pas 0 ?
"abc" vs "abcd"...

Quand la boucle finit, une string peut être plus courte que l'autre. "abc" vs "abcd" → s1[3]='\0', s2[3]='d'. La diff 0 - 100 = -100 donne le bon signe. Si égales, '\0' - '\0' = 0.

+
strcmp("A", "a") retourne quoi ?
Table ASCII...

'A' = 65, 'a' = 97. Donc 65 - 97 = -32. Les majuscules sont "plus petites" que les minuscules en ASCII. strcmp est case-sensitive.

Pièges déjoués

3 pièges rencontrés sur cet exo

SYNTAXE
PIÈGE #1
✕if s1[i] != s2[i]
✓if (s1[i] != s2[i])
Le piège : oublier les parenthèses du if. En C, elles sont obligatoires. Pas comme Python.
SYNTAXE
PIÈGE #2
✕return (s1[i] - s2[i])
✓return (s1[i] - s2[i]);
Le piège : oublier le point-virgule. Chaque instruction en C finit par ;. Le compilateur te le dira, mais ça coûte du temps à l'exam.
LOGIQUE
PIÈGE #3
✕return (0); après la boucle
✓return (s1[i] - s2[i]); après la boucle
Le piège : "abc" vs "abcd" — la boucle s'arrête car s1[3] == '\0', mais les strings ne sont PAS égales. Il faut retourner la diff même après la boucle pour gérer les longueurs différentes.

Pattern réutilisable

Parcours parallèle de deux strings — strncmp, ft_strncmp...

  1. Boucle tant que s1[i] && s2[i] — les DEUX doivent être non-nuls
  2. Comparer s1[i] et s2[i] à chaque tour
  3. Si différents → return (s1[i] - s2[i]) immédiatement
  4. Après la boucle → return (s1[i] - s2[i]) aussi (gère les longueurs différentes)
