Code final

Programme complet — write only, pas de fonctions interdites

alpha_mirror.c 
#include <unistd.h>

int main(int argc, char **argv)
{
    int i = 0;
    int c = 219;  // 'a' + 'z' = 97 + 122
    int b = 155;  // 'A' + 'Z' = 65 + 90

    if (argc != 2)
    {
        write(1, "\n", 1);
        return 0;
    }
    while (argv[1][i])
    {
        if (argv[1][i] >= 'a' && argv[1][i] <= 'z')
        {
            argv[1][i] = c - argv[1][i];
            write(1, &argv[1][i], 1);
        }
        else if (argv[1][i] >= 'A' && argv[1][i] <= 'Z')
        {
            argv[1][i] = b - argv[1][i];
            write(1, &argv[1][i], 1);
        }
        else
            write(1, &argv[1][i], 1);
        i++;
    }
    write(1, "\n", 1);
}

Flashcards

Réponds dans ta tête AVANT de cliquer

+
Quelle est la constante magique pour les minuscules ?
Pense à la table ASCII...

219 = 'a' + 'z' = 97 + 122. Le miroir de n'importe quelle minuscule x est 219 - x.

+
Et pour les majuscules ?
Même logique, autres bornes...

155 = 'A' + 'Z' = 65 + 90. Le miroir d'une majuscule X est 155 - X.

+
Comment obtenir le miroir de la lettre 'c' ?
Applique la formule...

219 - 'c' = 219 - 99 = 120 = 'x'. Vérification : c est la 3e lettre, x est la 3e depuis la fin.

+
Que faire si argc != 2 ?
Cas spécial du sujet...

Afficher juste un newline (write(1, "\n", 1)) et return. Pas de message d'erreur, pas de crash — juste \n.

+
Les caractères non-alphabétiques changent-ils ?
Espaces, ponctuation, chiffres...

Non, ils sont affichés tels quels. Le else final dans la boucle gère ce cas : write(1, &argv[1][i], 1) sans transformation.

Pattern réutilisable

Somme constante pour miroir — cipher, ROT13, symétrie...

  1. Identifier l'intervalle : bornes s1 et s2 (ex: 'a' et 'z')
  2. Calculer la constante : K = s1 + s2 (ici 219 ou 155)
  3. Appliquer le miroir : miroir(x) = K - x
  4. Gérer chaque casse séparément avec sa propre constante
  5. Laisser les caractères hors intervalle inchangés
FORMULE GÉNÉRALE
miroir(x) = borne_min + borne_max - x
'a' + 'z' - 'a' = 'z'   ✓
'a' + 'z' - 'z' = 'a'   ✓
'A' + 'Z' - 'M' = 'N'  ✓

CHALLENGE 1
ROT13
Décalage cyclique de 13 au lieu du miroir. La formule change : modulo au lieu de soustraction. Quelle constante utiliser ?
// Décaler chaque lettre de 13 positions (cyclique)
Indice : 'a' + 13 = 'n', 'n' + 13 = 'a' (mod 26). ROT13 est son propre inverse.
CHALLENGE 2
Cipher César
Décalage avec une clé variable (argv[2]). Même structure if/else if, mais la transformation change.
// Décaler chaque lettre de N positions (clé = argv[2])
Indice : gérer le wrap-around avec modulo 26.
CHALLENGE 3
alpha_mirror + chiffres
Même miroir alphabétique, mais aussi inverser les chiffres : '0'↔'9', '1'↔'8', '5'↔'4'. Quelle constante pour les chiffres ?
// '0' + '9' = 48 + 57 = 105
Indice : ajouter un troisième bloc if pour les digits avec la constante 105.
