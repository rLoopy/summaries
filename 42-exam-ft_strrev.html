ft_strrev.c 
char	*ft_strrev(char *str)
{
	int i = 0;
	int j = 0;
	char tmp;
	while (str[i])
		i++;
	i--;
	while (i >= j)
	{
		tmp = str[i];
		str[i] = str[j];
		str[j] = tmp;
		j++;
		i--;
	}
	return (str);
}

Que signifie "in-place" ?
Pas de nouveau tableau...

Modifier directement la string passée en paramètre, sans en créer une nouvelle. On travaille sur le même pointeur str.

+
De combien de variables temporaires as-tu besoin pour un swap ?
Pense au minimum...

Une seule : tmp. On sauvegarde une valeur, on écrase, puis on restaure. Trois lignes suffisent.

Quand s'arrête la boucle de swap ?
Les index se rapprochent...

Quand i >= j (les index se croisent au milieu). On peut aussi utiliser i > j — quand i == j c'est le char du milieu, pas besoin de le swapper avec lui-même.

Le sujet le demande explicitement...

Le pointeur str (le même qu'en entrée). La string a été modifiée in-place, on retourne le paramètre.

Trace le code mentalement...

i commence à 0, while(str[i]) ne s'exécute pas, i-- donne -1, la boucle while (i >= j) est fausse d'entrée → retourne str intact.

Pièges déjoués

4 pièges — chaque carte = une leçon gravée

LOGIQUE
PIÈGE #1
✕// pas de i-- après while(str[i])
✓while(str[i]) i++; i--;
Le piège : après while(str[i]), i pointe sur '\0'. Il faut i-- pour viser le dernier vrai caractère.
IN-PLACE
PIÈGE #2
✕char copy[100]; // deuxième tableau
✓tmp = str[i]; str[i] = str[j]; str[j] = tmp;
Le piège : le sujet dit «in-place». Créer un deuxième tableau viole la contrainte. On swap directement.
BOUCLE
PIÈGE #3
✕while (i > j) (marche aussi)
✓while (i >= j)
Le piège : i > j fonctionne aussi (quand i == j c'est le char du milieu, le swap est inutile). Mais >= est plus safe et explicite.
RETURN
PIÈGE #4
✕// oubli du return
✓return (str);
Le piège : le prototype retourne char *. Même si la string est modifiée in-place, il faut retourner le paramètre.

Pattern réutilisable

Deux pointeurs convergents — tri, palindrome, partition...

  1. Calculer la longueur avec while(str[i]) i++ puis i-- pour pointer le dernier char
  2. Initialiser deux index : j = 0 (début) et i (fin)
  3. Tant que i >= j : swap str[i] et str[j] avec une variable tmp
  4. Avancer les deux index : j++ et i-- — ils convergent vers le milieu
  5. Return str
OÙ RÉUTILISER CE PATTERN
Palindrome check — deux index convergents, comparer au lieu de swapper
Partition (quicksort) — deux pointeurs qui avancent selon une condition
Tri par sélection — un pointeur fixe, un qui parcourt
Inverser les voyelles — même logique, mais sauter les consonnes

Exercices de transfert

CHALLENGE 1
Palindrome check
Vérifier si une string est un palindrome. Même technique deux pointeurs, mais on compare au lieu de swapper.
int is_palindrome(char *str);
Indice : si str[i] != str[j] → return 0. Sinon, continuer jusqu'au croisement.
CHALLENGE 2
Inverser les voyelles
Inverser uniquement les voyelles d'une string, sans toucher aux consonnes.
char *reverse_vowels(char *str);
Indice : avancer i et j seulement quand ils pointent sur une voyelle, puis swap.
CHALLENGE 3
ft_strrev récursif
Réécrire ft_strrev en récursif. Le swap se fait à chaque appel, les index avancent via les paramètres.
void rev_rec(char *str, int i, int j);
Indice : cas de base = i < j. Sinon, swap + appel avec (i-1, j+1).
