Le concept : autoresearch

Inspiré d'Andrej Karpathy. Au lieu d'améliorer un prompt manuellement, un agent IA le fait en boucle :

  • Fait un petit changement au prompt
  • Teste le résultat
  • Garde si c'est mieux, annule sinon
  • Recommence. Encore et encore.
📋

Le scoring : ta checklist

Tu définis 3-6 questions oui/non qui décrivent un "bon" output :

  • "Le headline mentionne un pain point concret ?"
  • "Zéro buzzword dans le texte ?"
  • "Le CTA est clair et actionnable ?"

L'agent utilise cette checklist pour noter chaque itération. Pas de vibes, que du mesurable.

⚙️

Le process en 6 étapes

  • Télécharge le skill et choisis quel skill améliorer
  • L'agent te pose 3 questions : quel skill, quels inputs de test, quels critères
  • Il teste et affiche ton score de base
  • Dashboard live dans le navigateur (auto-refresh 10s)
  • L'agent boucle tout seul : analyse → modifie → teste → garde/revert
  • S'arrête à 95%+ ou quand tu le stop
