La solution : l'auto-audit

Un seul prompt qui fait auditer ton setup entier par Claude. Il vérifie chaque règle contre 5 filtres :

  • Le modèle fait-il déjà ça nativement ?
  • Est-ce que ça contredit une autre règle ?
  • Est-ce que c'est trop vague pour être utile ?
  • Est-ce un doublon ?
  • Est-ce encore pertinent aujourd'hui ?

Audit my entire Claude setup. Read every CLAUDE.md, every skill, and every context file. For each rule or instruction, check: (1) Does the model already do this by default?
