Code final

camel_to_snake.c 
#include <unistd.h>
#include <stdlib.h>

int main(int argc, char **argv)
{
	if (argc != 2)
	{
		write(1, "\n", 1);
		return 0;
	}
	int i = 0;
	while (argv[1][i])
	{
		while (argv[1][i] >= 'a' && argv[1][i] <= 'z')
		{
			write(1, &argv[1][i], 1);
			i++;
		}
		if (argv[1][i] >= 'A' && argv[1][i] <= 'Z')
		{
			write(1, "_", 1);
			argv[1][i] = argv[1][i] + 32;
			write(1, &argv[1][i], 1);
			i++;
		}
	}
	write(1, "\n", 1);
	return 0;
}

Flashcards

Réponds dans ta tête AVANT de cliquer

+
Comment transformer une majuscule en minuscule ?
Pense à la table ASCII...

Ajouter 32 au code ASCII du caractère. 'A' + 32 = 'a', 'Z' + 32 = 'z'. L'espace entre les blocs majuscules et minuscules dans la table ASCII est exactement 32.

+
Que faire AVANT d'écrire le char en minuscule ?
Le underscore doit venir...

Ecrire un underscore _ avec write(1, "_", 1). L'ordre est : 1° write "_", 2° convertir +32, 3° write le char converti.

+
Le while interne copie quoi ?
Quelle catégorie de caractère...

Tous les caractères minuscules ('a' à 'z') tels quels, un par un avec write. Il s'arrête dès qu'il tombe sur autre chose (une majuscule ou '\0').

+
Quand le if se déclenche ?
Après le while interne...

Quand on tombe sur une majuscule ('A' à 'Z'). Le while interne s'est arrêté, le if prend la main pour écrire _ + la version minuscule.

+
"aBC" donne quoi ?
Trace le code lettre par lettre...

a_b_c. Tour 1 : while copie a, if voit B → write _b. Tour 2 : while ne copie rien (C est majuscule), if voit C → write _c. Chaque majuscule est précédée de _.

Pièges déjoués

4 pièges — chaque carte = une leçon gravée

ACCOLADES
PIÈGE #1
✕write("\n") dans le while externe
✓write("\n") APRÈS le while
Le piège : accolade fermante mal placée → le write("\n") et le return 0 se retrouvent à l'intérieur du while. Le programme quitte dès le premier tour.
UNDERSCORE
PIÈGE #2
✕// oublier write("_", 1)
✓write(1, "_", 1); // avant +32
Le piège : sans write("_"), on obtient "helloworld" au lieu de "hello_world". L'underscore est la raison d'être de l'exo.
+32
PIÈGE #3
✕// oublier le +32
✓argv[1][i] = argv[1][i] + 32;
Le piège : sans la conversion, on écrit "hello_World" au lieu de "hello_world". Le +32 doit modifier le char AVANT le second write.
ARGC
PIÈGE #4
✕// pas de check argc
✓if (argc != 2) { write...; return 0; }
Le piège : sans check de argc, le programme crash si on n'a pas d'argument. Le sujet dit explicitement : argc != 2 → juste un newline.
4

Pattern réutilisable

Double while + if — scanner et transformer selon une condition

  1. Vérifier argc != 2 en premier — write newline + return si vrai
  2. Initialiser int i = 0, entrer dans le while principal tant que argv[1][i] != '\0'
  3. While interne : copier les minuscules ('a' <= c <= 'z') avec write et i++
  4. If majuscule ('A' <= c <= 'Z') : write "_", ajouter 32, write le char converti, i++
  5. Après le while principal : write le newline final
INVERSE EXACT : snake_to_camel
camel_to_snake — majuscule → write _ + char + 32
snake_to_camel — underscore → skip + char - 32 (la réciproque exacte)
str-capitalizer — touche au premier char de chaque mot
Principe — double while + if : copier le cas normal, transformer le cas spécial

Exercices de transfert

Même pattern, exo différent — solidifie l'apprentissage

CHALLENGE 1
snake_to_camel
L'inverse exact de cet exo. Même double while + if, mais la condition est inversée : underscore → skip + char suivant en majuscule (- 32).
// "here_is_a_word" → "hereIsAWord"
Indice : while copie si c != '_', if voit '_' → i++, char suivant - 32.
CHALLENGE 2
str-capitalizer / rstr-capitalizer
Mettre en majuscule la première lettre de chaque mot. Même logique : détecter un délimiteur (espace), puis transformer le char suivant.
// "hello world" → "Hello World"
Indice : après un espace (ou en début), prochain char minuscule → - 32.
CHALLENGE 3
Détecter plusieurs conventions
Généraliser : détecter si l'entrée est camelCase, snake_case, ou PascalCase et convertir vers snake_case dans tous les cas.
// "HelloWorld" ou "helloWorld" → "hello_world"
Indice : le test de majuscule ('A'-'Z') fonctionne pour PascalCase aussi — juste passer la première lettre sans underscore.
